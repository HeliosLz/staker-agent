## 🛠️ 技术栈

### 前端
- **框架**: React 18
- **构建工具**: Vite
- **路由**: React Router v6
- **样式**: Tailwind CSS
- **组件库**: shadcn/ui (Radix UI + Tailwind)
- **图表**: Recharts
- **终端**: xterm.js
- **状态管理**: Zustand (轻量级)
- **HTTP 客户端**: Axios
- **WebSocket**: native WebSocket API

### 后端
- **框架**: Flask
- **WebSocket**: Flask-SocketIO
- **CORS**: Flask-CORS
- **API**: RESTful
- **复用**: 现有 core/ 模块

## 🔌 API 设计

### REST API

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/env/check` | 环境检测 |
| POST | `/api/setup/install` | 安装依赖 |
| POST | `/api/config/generate` | 生成配置 |
| POST | `/api/keys/generate` | 生成密钥 |
| POST | `/api/deploy/start` | 部署节点 |
| GET | `/api/status` | 节点状态 |
| POST | `/api/node/restart` | 重启节点 |
| POST | `/api/node/stop` | 停止节点 |
| GET | `/api/logs` | 获取日志 |

### WebSocket

| 事件 | 方向 | 数据 |
|------|------|------|
| `connect` | Client → Server | 连接 |
| `subscribe_logs` | Client → Server | 订阅日志 |
| `log_stream` | Server → Client | 日志流 |
| `status_update` | Server → Client | 状态更新 |
